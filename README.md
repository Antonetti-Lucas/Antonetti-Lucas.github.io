# antonetti-lucas.github.io

Personal portfolio of Lucas Oliveira Antonetti: computer vision and continual learning research at the Recogna Lab, UNESP Bauru.

Live at **https://antonetti-lucas.github.io**

Static site in plain HTML, CSS and JavaScript (no build step), with Windows XP touches: a dark "Royale Noir" theme by default, a light "Luna" theme, and an English/Portuguese toggle. Both choices are saved in the browser.

Project screenshots come from each project's own repository.
